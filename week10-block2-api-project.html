What is an API? 🌐

A web page is made for humans 👀

An API is a URL made for programs 🤖, and it returns data, not a layout.

https://rest.ensembl.org / lookup/symbol / homo_sapiens / BRCA2
        server              what to do      species       gene

Big biological databases all have one: Ensembl, NCBI, UniProt, PDB… 🧬

Asking from Python 🐍

pip3 install requests
import requests

url = "https://rest.ensembl.org/lookup/symbol/homo_sapiens/BRCA2"
response = requests.get(url, headers={"Content-Type": "application/json"})
response.raise_for_status()      # stop with an error if something went wrong

gene = response.json()           # JSON → dictionary
print(gene["display_name"], gene["seq_region_name"])
print("Length:", gene["end"] - gene["start"] + 1, "bp")

requests is just another library: someone else wrote the hard part 📦

13–20 min. Show what happens with a typo in the gene name: raise_for_status() gives an HTTPError (400). That’s the same idea as FileNotFoundError: the outside world can fail.

Many genes → a table 📋

The bridge from last week: list of dictionaries → DataFrame 🪄

import pandas as pd
import requests

genes = ["BRCA1", "BRCA2", "TP53", "EGFR", "MYC"]
rows = []

for symbol in genes:
    url = f"https://rest.ensembl.org/lookup/symbol/homo_sapiens/{symbol}"
    r = requests.get(url, headers={"Content-Type": "application/json"})
    r.raise_for_status()
    g = r.json()
    rows.append({"gene": symbol, "chromosome": g["seq_region_name"],
                 "length": g["end"] - g["start"] + 1})

df = pd.DataFrame(rows)
df.to_csv("results/genes.csv", index=False)     # save it! 💾

20–27 min. Every piece is something they know: loop (w5), dict (w6), list of dicts → DataFrame (w9 bonus), to_csv (w9).

Be a polite client 🙏

  • Save what you downloaded → work on the CSV, not the API 💾
  • Don’t ask 10 000 times in a loop: there are rate limits ⏳
  • Add a small pause if you ask many times: time.sleep(0.2)
  • No internet = your analysis still runs from the saved file ✅

Download once, analyse many times. 🔁

27–30 min. Important for the project and the oral exam: their tool must run without the network.

Your final project 🚀

The idea 💡

Build one small tool in Python that answers one question about real biological data.

It brings together everything:

Skill From week
reading files, functions, loops 3–7 🐍

pandas analysis 9 🐼
plots 10 📊
(optional) data from an API 10 🌐

45–50 min. Energy up here, this is the start of the most important part of the course.

Requirements ✅

Your tool must:

  • 📄 read a real data file (FASTA, CSV, or data you downloaded and saved)
  • 🧩 use at least 3 functions with clear names
  • 🐼 do an analysis with pandas
  • 📊 save at least one plot to results/
  • 🛡️ show a friendly message if the input file is missing
  • 📖 have a README.md with how to run it
  • 📈 have commits spread over several days

And the most important one: you can explain every line 🗣️

50–55 min. These match the final checklist in week 13, so nothing will surprise them later.

Ideas, if you need one 🌱

  • 🧬 GC content and length of all sequences in a FASTA file, per organism, with a plot
  • 🔬 Fetch 20 genes from Ensembl, compare lengths across chromosomes
  • 📋 A CSV from your own lab or course: clean it, summarise it, plot it
  • 🦠 Compare two genomes / gene sets: what is different?
  • 🎲 Your own idea, the best option if you have one!

Small and working > big and broken 🌱

55–60 min. Developers in the group can do something more ambitious (or in another language, as agreed).
