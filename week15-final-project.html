1 · Get the data 📥

Any topic works: biology, sport, movies, music, weather, your hobby… 🌍

  • 🌐 an API (Ensembl, UniProt, NCBI, weather, …) → save the result as CSV in data/
  • 📄 a CSV or 📗 Excel file, e.g. from Kaggle → put it in data/
  • 🧬 a FASTA file → turn it into a table first (id, length, GC content…)

Your data must have:

  • at least 50 rows
  • at least 2 numeric columns (e.g. length, price, rating, temperature)
  • at least 1 text / category column (e.g. chromosome, genre, country)

✅ The analysis runs from the saved file, without internet

The data requirements guarantee that all 5 required questions are possible. Files over ~50 MB: don’t commit, take a subset or describe in the README how to download.

2 · Explore the data 🔍

Describe your dataset with pandas, before asking any questions:

df.shape              # how many rows and columns?
df.dtypes             # which columns are numbers, which are text?
df.head()             # what does it look like?
df.isna().sum()       # missing values per column
df["column"].unique() # which categories are there?

Then in words (README): where does the data come from, what is one row, what does each column mean? 📝

“What is one row” is the most important question: one gene? one sample? one patient? Missing values: say what you did with them (dropped / kept / filled) and why.

3 · Five required questions ❓

Answer each with code, and write the answer in your README:

Q1 · What are the min, max, mean and median of your numeric columns? → describe()
🧬 median gene length · 🎬 median movie rating

Q2 · Which are the top 3 and bottom 3 rows by a numeric column? → sort_values()
🧬 3 longest / shortest genes · 🎬 3 best / worst rated movies

Q3 · How many rows per category, and the mean of a numeric column per category? → groupby()
🧬 genes per chromosome, mean length · 🎬 movies per genre, mean rating

Q4 · How many rows meet a condition you choose? What % of all rows? → df[...]
🧬 genes longer than 100 000 bp · 🎬 movies longer than 2 hours

Q5 · Are two numeric columns related? → corr() + scatter plot
🧬 length vs number of exons · 🎬 budget vs box office

These five work for any table that meets the data requirements on slide 1. Q1: ask them to comment if mean and median are very different (skewed data / outliers). Q5: correlation is not causation, one sentence about that in the README is enough.

pandas or numpy? 🐼🔢

Both are fine: use what you understand best ✅

Question pandas 🐼 numpy 🔢
Q1 · min, max, mean, median df["col"].describe() np.min(), np.max(), np.mean(), np.median()
Q2 · top 3 / bottom 3 df.nlargest(3, "col") np.sort(arr)[-3:]
Q4 · % meeting a condition (df["col"] > x).mean() * 100 np.mean(arr > x) * 100
Q5 · are two columns related? df["a"].corr(df["b"]) np.corrcoef(a, b)[0, 1]

A pandas column → a numpy array: arr = df["length"].to_numpy() 🔁

💡 numpy also helps in your own research: np.percentile() for outliers, np.log10() for very skewed data, np.where() for a new yes/no column

Q3 (groupby) has no simple numpy version: pandas is the right tool there, mention it if asked. (arr > x).mean(): True counts as 1, same trick as sum(gc > 0.5) in R.

main.py puts it together ▶️

The other files hold functions, main.py only calls them:

# scripts/main.py
from load_data import load_genes
from explore import describe_data
from questions import top_and_bottom, count_per_category
from plots import plot_length_histogram

df = load_genes("data/genes.csv")

describe_data(df)
top_and_bottom(df, column="length", n=3)
count_per_category(df, category="chromosome", value="length")
plot_length_histogram(df, "results/length_histogram.png")

Run the whole project: python scripts/main.py 🚀

📓 Prefer a notebook? Fine: analysis.ipynb imports from your .py files, the same way.

Same import idea as week 9 (modules). Run from the project root so the relative paths work.

Clean code 🧼

The test: can I read your code and understand it? 👀

✅ Do

  • clear names: gene_lengths, count_per_category()
  • short functions, each doing one thing
  • file paths as constants at the top
  • a comment where the why isn’t obvious

❌ Avoid

  • x, df2, test_final_v3()
  • one 300-line script
  • the same code copy-pasted 5×
  • old, commented-out code left behind

Copy-paste 5×: that’s a sign it should be a function with a parameter.
